## 📖 这是什么

你被困在一间只有一台老虎机的混凝土牢房里。

每一「期」（Deadline）都有一笔压在你头上的**债务**——在回合耗尽前，把金币**存进 ATM** 还清它。还不上，就进入死亡倒计时；再拖三个回合，地板会打开。

**赚钱的唯一方式，就是拉下拉杆。**

《四叶草深渊》把老虎机从「赌场」搬进了「牢房」：符号与图案的赔付引擎完全照搬真实老虎机的数学结构，但目标函数被彻底反转——你不是在追求娱乐，你是在**跑赢利息**。存得越早，7% 的复利越滚越快；犹豫一回合，数字就可能永远追不上。

本作是对 **Panik Arcade《CloverPit》** 的**非官方同人复刻**，从机制数值到界面气质都尽量向原作靠拢，并在此基础上做了大量可玩性补完（完整双结局链路、图鉴收集、通话记录、跨局解锁等）。

### 2️⃣ 旋转与费用

每回合开始时二选一：

- **多旋转** —— 花费拉杆费，获得 **7 次**旋转
- **少旋转** —— 同样的拉杆费，但只有 **3 次**旋转，回合结算时多给 **3 张券**

金币不够整轮时触发**欠转**（花光身上金币按比例折算次数）；身无分文则是**免费回合**——还能转，但图案不计酬，结算只有 1 券。

### 3️⃣ 计分公式

```
单个图案赔付 = 符号价值总和 × 符号倍率 × 图案倍数 × 图案倍率 × 触发次数
```

- **符号价值**：柠檬/樱桃 2、四叶草/铃铛 3、钻石/宝箱 5、幸运 7 → 7
- **图案基础倍率**：短连 0.5 → 三连 1.0 → 大横四连 2.0 → 巨横五连 3.0 → 锯齿 4.0 → 三角 7.0 → **天眼 14.0 → 大满贯 25.0**
- **大图案吞并小图案**（巨横吞横三连、三角吞锯齿），但**大满贯（15 格全同）不吞任何人**，会与其他图案同时结算

### 4️⃣ 幸运值与「怜悯」

每次旋转随机产生 0～15 点幸运：把等量格子**强制变成同一符号**。

> **15 点 = 保底大满贯。**

连续空转会触发机器的「怜悯」（橡皮筋加成），幸运值悄悄上涨——这是防止长时间零收益的体验保险。

### 5️⃣ 红色按钮 ⚡

大量幸运符带**充能**标记：平时不生效，只有点**红色按钮**才触发，每次消耗 1 格能量。能量在**每回合结算时自动 +1**。

> **正确节奏：先拉杆进入旋转，再按红按钮。** 红按钮只在旋转阶段可点，点按钮本身免费。

### 6️⃣ ATM、利息与幸运券

- **存入 ATM** 的金币按回合生息（基础 **7%**），是还债专用
- **身上**的金币用于拉杆与补货
- **幸运券**（绿色）是买幸运符的货币；回合结算、少旋转、提前结束本期都会给

> 💡 **尽早存钱吃利息**——这是本作最反直觉也最关键的策略。

### 7️⃣ 电话 ☎

第 2 期起，每期开始时电话会响：3 个选项选 1 个，可花券重掷。

- **普通来电**（24 通）：全是增益
- **红色来电**（8 通）：超值收益，但**接听即永久放弃神圣资格**
- **神圣来电**（8 通）：神圣模式限定

**连续挂断 3 次红色来电**会开启**神圣之路**：此后 666 化为 **999**（不再没收金币），并可能出现神圣来电与神圣符文。

所有接听 / 挂断 / 推迟过的电话都会记入 **☎ 通话记录**，含对方的回应台词。

### 8️⃣ 666 / 999 😈

第 3 期起，每次旋转后可能降下 **6 / 66 / 666**：

| 结果 | 效果 |
|---|---|
| **6** | 只是印在盘上占格（固定 7.5% 概率） |
| **66** | 占两格（固定 6% 概率） |
| **666** | **没收本回合所得**；第 7 期起 = 身上全部金币，并在抽屉留下一块尸块 |

被 6 印上的格子不再参与图案判定。基础 666 概率 1.5%，硬上限 30%。

### 9️⃣ 幸运符 / 特性 / 修饰词

- **幸运符**：被动 / 随机触发 / 充能 / 即生效，共 **88 件**，靠**期末记忆包交易**与**结局**逐步解锁
- **特性**（7 种）：贪婪、野心、阴险、繁茂、赌徒、执念、投机——由电话能力贴到符文上
- **修饰词**（7 种）：金色（价值永久上涨）、代币（立即得钱）、票券、复现（图案多触发一次）、电池、锁链、**万能**（可替代该图案里的任意符号）

**抽屉**可以存放符文且不占容量，可来回倒腾。

### 🔟 尸块、钥匙与结局 💀

集齐 **5 块尸块**（骷髅 / 左臂 / 右臂 / 左腿 / 右腿）并解锁全部 **4 个抽屉**后，announcer 会递来钥匙：

| 结局 | 条件 | 内容 |
|---|---|---|
| 🌅 **白钥匙 · 上升** | 保持神圣模式（未接过红色来电） | 电梯上升，门开时是一片宁静的日出 |
| 🚪 **暗红钥匙 · 门后无门** | 接过红色来电 | 牢房只是悬在深渊上的混凝土柱之一 |

## 🏗️ 技术架构

### 设计原则

```
引擎零 DOM ── 数据纯声明 ── 表现层可降级
```

| 原则 | 落地方式 |
|---|---|
| **引擎零 DOM** | `engine.js` 不碰任何 DOM，可在 Node 中直接跑自动化对局 |
| **可播种随机** | 自研 mulberry32，内部状态可序列化 → 存档能精确续接随机序列 |
| **数据纯声明** | 符号 / 图案 / 债务 / 电话 / 记忆卡全在 `data.js` 里声明，改数值不用动逻辑 |
| **表现层可降级** | GSAP 缺失或系统开启「减少动态效果」时，动效自动退化为无动画，**永不影响逻辑** |
| **零外部素材** | 图标为内联 SVG，音效为 WebAudio 实时合成，不加载任何图片 / 音频文件 |

## 📊 数值设计

### 关于 RTP：本作刻意「不平衡」

传统老虎机把 RTP 控制在 80%–105% 以维持赌场盈利。**本作的目标函数完全相反**：

> 这是一个**债务竞速**游戏，不是赌场模拟。
> 基础 RTP 远大于 1 是**刻意的设计**——玩家必须能稳定赚钱，真正的压力来自**指数级上涨的债务**与**每回合复利**。

> 📐 **口径说明**：RTP 探针把金币补足以隔离「破产」干扰，且只跑第 1 期（不推进 666），因此它测的是**基础图案引擎的回报率**，不是全局 RTP——这属于有意隔离测量。

因此，请勿用传统 par sheet 的 RTP 目标来「对齐」本项目数值：两套机制不同（本作是**图案倍率制**，不是「连线数 × 符号赔付」）。

### 免费旋转的期望值口径

赠送旋转会**自我再触发**，凭感觉给次数会让期望次数发散（`B ≥ 1` 时直接爆炸）。因此所有赠送旋转都遵循：

```
B = Σ [ P(单次旋转触发 k 个连锁源) × 初始赠送次数(k) ]
E = 初始次数 n / (1 − B)      ← 含「免费旋转内再触发」的总期望次数
```

并额外加每回合**硬上限 60 次**（`FREE_SPIN_ROUND_CAP`），保证不会无限连锁。

## 📱 移动端与无障碍

- **响应式布局**：从手机竖屏到桌面宽屏均可玩
- **安全区适配**：`viewport-fit=cover` + `env(safe-area-inset-*)`，刘海 / 挖孔屏内容不被遮挡
- **触屏说明气泡**：手机没有悬停，点一下带说明的格子 / 按钮即弹出说明
- **动效降级**：系统开启「减少动态效果」时，全部 GSAP 动画自动关闭
- **键盘支持**：空格键 = 拉杆；Esc = 关闭弹窗
- **ARIA 标注**：弹窗带 `role="dialog"` / `aria-modal`，状态区带 `aria-live`

## 🎨 视觉风格

**暗色 CRT 工业风**：琥珀 / 铁锈 / 混凝土 / 深黑四色体系，唯一冷色点缀是四叶草的青柠绿。

盘面符号全部使用**内联双色 SVG**，刻意不用彩色 3D emoji——emoji 的饱和度、体积感与光影方向都和暗色工业风相冲突，且在不同系统上渲染尺寸完全不一致。

界面覆盖 CRT 扫描线、暗角、标题霓虹跑马灯等氛围层，全部由 CSS 实现。
